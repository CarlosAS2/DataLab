01 / AQUECIMENTO

Primeiro, a ideia por trás do código.

Imagine uma mochila com vários materiais e uma ficha com informações de uma pessoa. No JavaScript, usamos arrays para listas e objetos para conjuntos de características.

[ ]

Array = lista

Uma variável pode guardar vários itens em ordem. Exemplo: ["Ana", "Bia"].

#0

Índice = posição

Para acessar um item, usamos sua posição. A primeira posição é 0, não 1.

{ }

Objeto = ficha

Armazena pares de propriedade e valor. Exemplo: { nome: "Ana" }.
